# Demonstration walkthrough

Use fictional visits and public demonstration locations within verified routing coverage.

1. Load a fictional care day. Show the map, visit order, care durations, arrival windows, and summary metrics. Capture the care-day overview.
2. Increase a visit's care duration enough to miss a later arrival window. Recompute and show the explicit conflict. Capture the conflict screen.
3. Start in-app navigation on a verified road route. Capture a turn instruction. If using route simulation, retain its simulation label and describe it accurately.
4. On a physical device, disable Wi-Fi and cellular networking and recompute. Record successful offline operation only after verifying both map rendering and native routing.

Before sharing, review images and video for real client details and device notifications. Do not show fallback geometry as native road routing or present unfinished lock-screen integration as working.
